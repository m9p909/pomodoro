# Pomodoro Todo App Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a local-first Tauri 2 desktop pomodoro/todo app with a Rust-authoritative timer, SQLite persistence, a thin Svelte 5 UI, MIT license, and GitHub Actions CI/release.

**Architecture:** Rust owns validation, timer state, focus accounting, analytics, persistence, and alerts. Svelte renders snapshots and emits commands. A background Rust tick loop is authoritative and checkpoints active focus time. Typed IPC is generated with `tauri-specta`.

**Tech Stack:** Tauri 2.12, Rust 2024, rusqlite 0.41 (bundled SQLite), Svelte 5, TypeScript 6, Vite 8, Vitest 5, pnpm 12.

**Execution note:** Git commits are enabled at the user's request. Commit each completed task on `main`, inspect diffs before staging, and never commit generated build output or secrets.

## Global Constraints

- Focus is exactly 25 minutes; short break 5 minutes; long break 15 minutes after every fourth completed focus phase.
- All phase transitions are manual. Breaks may be skipped while pending, running, or paused.
- Only active focus elapsed time counts. Pauses, breaks, and system-sleep gaps do not.
- Focus time is checkpointed to SQLite while running. Startup recovery marks orphaned active sessions abandoned.
- A todo earns estimate progress only when it owns an entire completed focus phase. Any attribution switch forfeits credit permanently for that phase.
- Every completed focus phase advances the global cycle, including phases with task switches.
- SQLite is the only persistence. Data lives in the OS app-data directory. No network, telemetry, or external server.
- Tauri uses the OS WebView. Linux packages declare WebKitGTK.
- Svelte must contain no timer math, cycle logic, accounting, analytics aggregation, or ordering rules.
- The UI uses Svelte 5 runes syntax.
- All code must pass `cargo fmt --check`, Clippy with `-D warnings`, Rust tests, `pnpm check`, and `pnpm test`.
- Release targets: Linux x86_64 AppImage/DEB, Windows x86_64 MSI, macOS universal DMG.
- License: MIT, `Copyright (c) 2026 Pomodoro contributors`.

#[derive(Debug, Clone, Serialize, Type)]
#[serde(tag = "kind", content = "message", rename_all = "camelCase")]
pub enum AppError {
    Validation(String),
    NotFound(String),
    Storage(String),
    Timer(String),
}

impl std::fmt::Display for AppError {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        match self {
            Self::Validation(m) | Self::NotFound(m) | Self::Storage(m) | Self::Timer(m) => f.write_str(m),
        }
    }
}

impl std::error::Error for AppError {}

impl From<rusqlite::Error> for AppError {
    fn from(value: rusqlite::Error) -> Self {
        Self::Storage(value.to_string())
    }
}

impl From<std::io::Error> for AppError {
    fn from(value: std::io::Error) -> Self {
        Self::Storage(value.to_string())
    }
}

- [ ] **Step 3: Implement the clock abstraction**

In `clock.rs`:

```rust
use chrono::{Local, Utc};
use std::sync::Mutex;
use std::time::{Duration, Instant};

pub trait Clock: Send + Sync {
    fn utc_ms(&self) -> i64;
    fn mono_ms(&self) -> u64;
    fn local_day(&self) -> String;
}

pub struct SystemClock { start: Instant }
impl SystemClock {
    pub fn new() -> Self { Self { start: Instant::now() } }
}
impl Clock for SystemClock {
    fn utc_ms(&self) -> i64 { Utc::now().timestamp_millis() }
    fn mono_ms(&self) -> u64 { self.start.elapsed().as_millis() as u64 }
    fn local_day(&self) -> String { Local::now().format("%Y-%m-%d").to_string() }
}

pub struct FakeClock { state: Mutex<(i64, u64, String)> }
impl FakeClock {
    pub fn new(utc_ms: i64, mono_ms: u64, day: &str) -> Self {
        Self { state: Mutex::new((utc_ms, mono_ms, day.to_string())) }
    }
    pub fn advance(&self, ms: u64) {
        let mut s = self.state.lock().unwrap();
        s.0 += ms as i64;
        s.1 += ms;
    }
    pub fn set_day(&self, day: &str) { self.state.lock().unwrap().2 = day.to_string(); }
}
impl Clock for FakeClock {
    fn utc_ms(&self) -> i64 { self.state.lock().unwrap().0 }
    fn mono_ms(&self) -> u64 { self.state.lock().unwrap().1 }
    fn local_day(&self) -> String { self.state.lock().unwrap().2.clone() }
}
```

CREATE TABLE todos (
    id TEXT PRIMARY KEY,
    title TEXT NOT NULL,
    estimate_pomodoros INTEGER CHECK (estimate_pomodoros IS NULL OR estimate_pomodoros > 0),
    sort_order INTEGER NOT NULL,
    created_at INTEGER NOT NULL,
    updated_at INTEGER NOT NULL,
    completed_at INTEGER,
    deleted_at INTEGER
);

CREATE TABLE focus_sessions (
    id TEXT PRIMARY KEY,
    started_at INTEGER NOT NULL,
    ended_at INTEGER,
    last_checkpoint_at INTEGER NOT NULL,
    outcome TEXT NOT NULL CHECK (outcome IN ('active', 'completed', 'abandoned')),
    credit_todo_id TEXT REFERENCES todos(id)
);

CREATE TABLE focus_time (
    session_id TEXT NOT NULL REFERENCES focus_sessions(id) ON DELETE CASCADE,
    todo_id TEXT REFERENCES todos(id),
    bucket_key TEXT NOT NULL,
    local_day TEXT NOT NULL,
    active_ms INTEGER NOT NULL CHECK (active_ms >= 0),
    updated_at INTEGER NOT NULL,
    PRIMARY KEY (session_id, bucket_key, local_day)
);

CREATE INDEX idx_focus_time_day ON focus_time(local_day);
CREATE INDEX idx_focus_time_todo_day ON focus_time(todo_id, local_day);
CREATE INDEX idx_focus_sessions_credit ON focus_sessions(outcome, credit_todo_id);

CREATE TABLE settings (
    id INTEGER PRIMARY KEY CHECK (id = 1),

);

- [ ] **Step 3: Implement the timer core**

Fields:

```rust
pub struct TimerCore {
    state: TimerState,
    phase: Option<TimerPhase>,
    elapsed_ms: i64,
    session_id: Option<String>,
    session_started_at: Option<i64>,
    attributed_todo_id: Option<String>,
    credit_todo_id: Option<String>,
    last_mono_ms: Option<u64>,
    completed_focus_count: i64,
    muted: bool,
    persistence_warning: Option<String>,
    pending: HashMap<PendingKey, i64>,
    last_data_event_ms: u64,
}
```

`PendingKey` is `{ session_id, todo_id: Option<String>, local_day }`.

Behavior:

- `load`: recover active sessions, load settings into `completed_focus_count` and `muted`, return idle core.
- `start_focus(None)` from idle or `BreakPending` starts an unassigned session. From focus running/paused, switch attribution to unassigned, clear credit, and resume.
- `start_focus(Some(id))` starts or switches. Same todo while running is a no-op; same todo while paused resumes. Any different attribution sets `credit_todo_id = None` permanently.
- `start_focus` from `BreakRunning`/`BreakPaused` returns `AppError::Timer`.
- Focus start inserts an active session with `credit_todo_id` equal to the starting todo and `last_checkpoint_at = now`.
- `pause` flushes and freezes. `resume` sets `last_mono_ms`.
- `end_focus` flushes, marks the session abandoned, and returns to idle.
- `start_break` only from `BreakPending`; `skip_break` from pending/running/paused returns idle.
- `tick` always flushes any pending rows first, so failed writes retry even when idle.
- While focus runs, add the delta to the current `(session, todo, local_day)` bucket, flush, and complete when `elapsed_ms >= FOCUS_MS`.
- On focus completion: update session to completed, increment completed focus count, choose long break when `count % 4 == 0` else short, set `BreakPending`, clear attribution/session, and return an audible-following mute `FocusComplete` alert. Set `data_changed = true`.
- While a break runs, complete into `Idle` with a `BreakComplete` alert.
- `data_changed` is true every five seconds of focus and on completion.
- `snapshot` computes total/remaining from the current phase; idle shows 25:00. It looks up attributed todo title from the database.

- [ ] **Step 4: Implement checkpoint retry and warning**

`flush_pending` starts a transaction, upserts every pending row, updates each session's `last_checkpoint_at`, and commits. On success clear `pending` and `persistence_warning`. On failure keep pending rows and set a user-readable warning. This is the only place that decides a write warning.

export const EVENT_TIMER_ALERT = "timer-alert";

export function onTimerSnapshot(cb: (snapshot: TimerSnapshot) => void): Promise<UnlistenFn> {
  return listen<TimerSnapshot>(EVENT_TIMER_SNAPSHOT, (event) => cb(event.payload));
